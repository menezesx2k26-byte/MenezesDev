# MenezesDev — Cases Demonstrativos

**Versão:** 1.0  
**Status:** especificação pré-produção  
**Objetivo:** criar três projetos demonstrativos visualmente distintos para o portfólio inicial da MenezesDev.

---

# 1. Objetivo dos cases

Os três projetos demonstrativos devem provar que a MenezesDev consegue desenvolver sites para negócios de estilos, públicos e necessidades diferentes.

Cada projeto deve:

- possuir identidade própria;
- parecer um projeto comercial real;
- demonstrar uma categoria diferente de serviço;
- possuir design significativamente diferente dos outros;
- funcionar perfeitamente em desktop e mobile;
- evitar aparência de template reaproveitado;
- utilizar imagens produzidas especificamente para o conceito;
- utilizar tipografia apropriada ao nicho;
- apresentar recursos compatíveis com o pacote demonstrado.

Todos devem possuir a identificação:

**Conceito demonstrativo desenvolvido pela MenezesDev.**

Nenhum dos negócios apresentados deve ser descrito como cliente real.

---

# 2. Estrutura estratégica

| Projeto | Nicho | Pacote demonstrado | Objetivo |
|---|---|---|---|
| M47 Barber | Barbearia | Essencial — R$600+ | Mostrar força de uma landing page |
| Tavola 27 | Restaurante | Profissional — R$950+ | Mostrar site institucional visual |
| Prismae | Consultoria empresarial | Negócio — R$1.500+ | Mostrar geração de leads |

Os três cases devem parecer produtos diferentes construídos pela mesma empresa, e não três skins do mesmo template.

# CASE 01 — M47 BARBER

# 3. Conceito

**Nome:** M47 Barber  
**Segmento:** Barbearia contemporânea  
**Tipo:** conceito demonstrativo  
**Pacote representado:** Essencial — R$600+

## Objetivo comercial

Demonstrar como uma landing page relativamente simples pode transformar a apresentação de um pequeno negócio local.

O site deve mostrar que R$600 não significa:

- site improvisado;
- template barato;
- página sem personalidade.

Deve parecer um projeto visualmente forte mesmo possuindo apenas uma página.

---

# 4. Posicionamento

M47 é uma barbearia masculina urbana voltada a clientes que valorizam:

- pontualidade;
- acabamento;
- ambiente;
- estilo;
- facilidade para agendar.

A personalidade da marca é:

**urbana, precisa, masculina e contemporânea.**

Evitar estética:

- barbearia vintage clichê;
- poste barber vermelho e azul;
- bigode;
- caveira;
- navalhas cruzadas;
- madeira envelhecida.

A proposta deve parecer uma barbearia criada em 2026.
