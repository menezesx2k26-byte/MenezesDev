# 5. Discount Calculator — RETAIN as distinct from Percentage Calculator

Current Docelf June 2026 US evidence:

- `percent off calculator` ~**22,200** / **$5.19 CPC**;
- `percentage off calculator` ~**12,100** / **$5.19 CPC**;
- `discount percentage calculator` ~1,600 in the exposed table.

The user intent is transactional/everyday-price oriented:

- original price;
- discount percentage;
- final sale price;
- amount saved;
- reverse discount calculations;
- optional stacked discounts if product design later permits.

Generic Percentage Calculator instead solves broad percentage relations/change and should not absorb shopping/discount intent merely because the arithmetic shares primitives.

## Decision

**Retain Discount Calculator.**

Do not generate percentage-specific doorway URLs such as `/20-percent-off-50`; one capable calculator should handle values dynamically.

Source:
- https://www.semrush.com/website/docelf.com/overview/
