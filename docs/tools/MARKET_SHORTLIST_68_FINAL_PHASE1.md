# 4. Explicit consolidations represented in the 68

The following are product/SEO consolidation decisions, not missing functionality:

- Simple Interest is a mode of Interest Calculator.
- JSON Minifier is a mode of JSON Formatter.
- File Hashing is a mode of SHA-256 Hash Generator.
- JSON → CSV is the reverse mode of the CSV ↔ JSON product; no separate Launch URL is implied.
- numeric binary/octal/decimal/hex directions live inside Number Base Converter.
- Binary Translator remains separate because text/UTF-8 ↔ binary bytes is a different intent.

The Phase-5 IA spec will choose final canonical route names and prevent doorway siblings.
