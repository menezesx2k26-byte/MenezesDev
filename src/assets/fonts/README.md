# Fontes locais

As fontes deste diretório são cópias WOFF2 oficiais hospedadas pelo Google Fonts e usadas sem requisições de fonte em runtime.

| Arquivo | Família | Intervalo usado | Origem oficial |
| --- | --- | --- | --- |
| `inter-latin.woff2` | Inter | 400–600 | `fonts.gstatic.com`, CSS2 do Google Fonts |
| `manrope-latin.woff2` | Manrope | 400–800 | `fonts.gstatic.com`, CSS2 do Google Fonts |
| `archivo-latin.woff2` | Archivo | 700–800 | `fonts.gstatic.com`, CSS2 do Google Fonts |
| `cormorant-garamond-latin.woff2` | Cormorant Garamond | 500–600 | `fonts.gstatic.com`, CSS2 do Google Fonts |
| `plus-jakarta-sans-latin.woff2` | Plus Jakarta Sans | 600–700 | `fonts.gstatic.com`, CSS2 do Google Fonts |

Cada família mantém sua licença OFL correspondente em `licenses/`. Os arquivos são subsets Latin; a UI inclui fallbacks de sistema para caracteres fora desse subset.
